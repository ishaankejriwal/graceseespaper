# Official Copernicus template

Downloaded on 9 October 2026 from the LaTeX package linked on the
[HESS submission page](https://www.hydrology-and-earth-system-sciences.net/submission.html#templates).

Source archive:
https://www.hydrology-and-earth-system-sciences.net/Copernicus_LaTeX_Package.zip

Archive SHA-256:
`996038225515b56856769e7de478a7df5ef97e425e645147ea57dc72adfed4dd`

The website and bundled README identify the package as **7.16, 3 September
2026**. The actual class file in that archive identifies itself as
**10.1.35, 8 September 2026**; the README's class-version entry is older.
The files here are the unmodified publisher downloads. The active copies
of `copernicus.cls`, `copernicus.cfg` and `copernicus.bst` in `paper/`
match these files. `template.tex` is retained for reference, and `main.tex`
uses its manuscript class and standard author, affiliation, equal
contribution, appendix and end-matter commands.

For initial review, the current web instructions take precedence over
older comments in the template: figures and tables stay near their first
mention, the manuscript stays in one column, and code/data availability
follows the appendices.
