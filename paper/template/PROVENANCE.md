# Copernicus LaTeX template

These are the unmodified files from the Copernicus LaTeX package linked on the
[HESS submission page](https://www.hydrology-and-earth-system-sciences.net/submission.html#templates),
downloaded on 9 October 2026 from
https://www.hydrology-and-earth-system-sciences.net/Copernicus_LaTeX_Package.zip
(SHA-256 `996038225515b56856769e7de478a7df5ef97e425e645147ea57dc72adfed4dd`).

The website and the bundled README give the package version as 7.16, 3 September 2026.
The class file itself reports version 10.1.35, 8 September 2026; the README lists an
older class version.

The copies of `copernicus.cls`, `copernicus.cfg` and `copernicus.bst` in `paper/` have
the same content as these files (the `.bst` differs only in line endings). `template.tex`
is kept for reference. `main.tex` uses its manuscript class and its standard commands for
authors, affiliations, equal contribution, appendices and end matter.

Where the template's comments are older than the current web instructions for initial
review, we follow the web instructions: figures and tables stay near their first mention,
the manuscript is in one column, and the code and data availability section follows the
appendices.
